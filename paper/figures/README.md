# paper/figures

Rysunki i wykresy tekstu badania (`\includegraphics{nazwa}` szuka tu, zob. `\graphicspath` w `main.tex`).

- Wykresy wyników generują skrypty z `src/analysis/`; nie poprawia się ich ręcznie, tylko skrypt.
- Schematy rysujemy w TikZ wprost w tekście (jak rysunek środowiska w `sections/03-method.tex`) albo jako PDF lub
  PNG z opisem, czym powstały.
- Nazwy: małe litery i myślniki, np. `success-by-model.pdf`.
