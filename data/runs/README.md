# data/runs

Zapisy przebiegów modeli: każde wywołanie narzędzia i każda odpowiedź modelu, w formacie zapisu przebiegu
z `schemas/`. Osobno pilotaż i pełne badanie (podfoldery powstają razem z pierwszą serią).

Każdy zapis wskazuje konfigurację z `experiments/`, z której powstał, wersję modelu i datę przebiegu. Zapisów się
nie zmienia ani nie usuwa po fakcie (także nieudanych przebiegów: są częścią wyników).
