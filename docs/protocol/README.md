# docs/protocol

Protokół eksperymentu, ustalony **przed** zbieraniem danych pełnego badania i zmieniany tylko z zapisem zmiany.

Co tu trafi:

- prompt systemowy i opis zadania dla każdej rodziny zadań (neutralny, bez podpowiedzi algorytmu);
- co model wie o zadaniu (rozmiar N, cel; wartości danych nie);
- sposób zebrania deklaracji algorytmu;
- ustawienia modeli (temperatura, rozumowanie), limity kroków, czasu i tokenów, warunki zatrzymania;
- wstrzykiwanie błędów narzędzi i wywołania równoległe;
- rozmiary zadań, liczba powtórzeń, ziarna;
- plan analizy: miary, przedziały ufności, testy porównań modeli, próg odległości klasyfikatora i reguła hybrydy.

Zmiany po pilotażu zapisujemy tu z datą i powodem.
