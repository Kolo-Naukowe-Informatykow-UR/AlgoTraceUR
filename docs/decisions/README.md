# docs/decisions

Decyzje projektu, które powinien znać cały zespół: jeden plik na decyzję, nazwa `NNNN-krotki-opis.md`
(np. `0001-stos-technologiczny.md`).

Każdy plik ma cztery części:

- **Kontekst:** co trzeba było rozstrzygnąć i dlaczego.
- **Decyzja:** co wybraliśmy.
- **Odrzucone:** inne opcje i powód.
- **Skutki:** co z tego wynika dla kodu, danych albo tekstu.

Pierwsze decyzje do zapisania: stos technologiczny modułów, licencje, sposób budowania tekstu badania i jego język,
granica między środowiskiem bazowym a pracą zespołu.
