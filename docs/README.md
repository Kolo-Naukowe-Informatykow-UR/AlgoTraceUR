# docs

Dokumentacja projektu, która nie jest kodem ani tekstem badania.

| Folder | Co tam trafi |
|---|---|
| `decisions/` | zapisy decyzji projektu (jedna decyzja na plik) |
| `protocol/` | protokół eksperymentu i plan analizy wyników, ustalone przed zbieraniem danych |
| `meetings/` | notatki ze spotkań zespołu i kopie raportów co 2 tygodnie |

Tu trafia też opis różnic między API dostawców (z adapterów) i raport walidacji analizatora, jeśli nie wejdą do
tekstu badania.
