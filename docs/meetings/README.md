# docs/meetings

Notatki ze spotkań zespołu i kopie raportów co 2 tygodnie: jeden plik na spotkanie albo raport, nazwa
`RRRR-MM-DD-krotki-opis.md` (np. `2026-12-03-pierwsze-spotkanie.md`).

Notatka ze spotkania: kto był (role), co ustaliliśmy, kto co robi do kiedy, otwarte sprawy.

Raport co 2 tygodnie: wykonane zadania, plan, problemy, aktywność członków, postęp KPI, linki do rezultatów.
